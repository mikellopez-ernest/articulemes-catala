# Articulemes en catala

Eina educativa per generar fitxes d'articulemes a partir de paraules en catala.

## Web

GitHub Pages publica el contingut de `docs/`. La pagina principal es
`docs/index.html`, amb les fotografies incorporades al mateix fitxer HTML.
No necessita servidor d'aplicacions, dependencies ni comptes d'usuari.

Per actualitzar la web, edita `docs/index.html` i publica els canvis.

## Fitxers originals

`Articulemes_catala.html`, `assets/`, `color_mapping.json` i `build.py`
provenen del paquet original. El generador `build.py` fa referencia a rutes
de l'entorn original i necessita un PDF que no esta inclos en aquest paquet;
no cal executar-lo per publicar ni utilitzar la web.
